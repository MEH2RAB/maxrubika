    در این بخش متدهای کلاس Rubino به همراه توضیحات و پارامترهای هر متد معرفی شده‌اند.

    get_me

    دریافت اطلاعات پروفایل.

    پارامترها:

    • my_profile (اختیاری): شناسه یا نام کاربری پروفایل؛ پیش‌فرض self.profile_id است.

    مثال:

    Python
    from maxrubika import Rubino

with Rubino(session="mySession") as rubino:
    result = rubino.get_me()
    print(result)

        target_profile="@admin_username",

    • avatar_thumbnail (اختیاری): مسیر فایل تصویر بندانگشتی پروفایل.

    from maxrubika import Rubino

    • target_profile: شناسه یا نام کاربری مالک پست.
    • post: لینک یا شناسه پست.
    • target_object_type: نوع مقصد؛ بدون حساسیت به بزرگی حروف.
    • target_object_id (اختیاری): شناسه مقصد، مانند گفتگو، کانال یا گروه؛ پیش‌فرض None است.
    • type (اختیاری): نوع اشتراک‌گذاری؛ پیش‌فرض Message است.
    • track_id (اختیاری): شناسه رهگیری؛ پیش‌فرض None است.
    • my_profile (اختیاری): پروفایلی که اشتراک‌گذاری را انجام می‌دهد؛ پیش‌فرض self.profile_id است.

    مثال:

    Python
    from maxrubika import Rubino

with Rubino(session="mySession") as rubino:
    result = rubino.update_post_share_count(
        target_profile="@target_username",
        post="POST_ID",
        target_object_type='User'
    )
    print(result)
