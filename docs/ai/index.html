    Rubino

    Rubino provides a dedicated API for working with Rubika profiles and content. Use the documented methods for profile management, pages, posts, stories, comments, likes, follows, search, feed, media upload/download, and reporting.

    Rubino Methods · Rubino More · 101 documented methods with examples.

    from maxrubika import Rubino

with Rubino(session="mySession") as rubino:
    profile = rubino.get_me()
    print(profile)

    Rubino currently documents API version 1 as the usable version. For exact method names, parameters, defaults, and examples, read the Rubino Methods page; do not infer undocumented behavior.
